# TRACE Docs

This folder is the source of truth for contracts, architecture, and task authoring.

## Suggested read order
1. `BLUEPRINT.md` — normative ABI/contracts.
2. `SYSTEM_ARCHITECTURE.md` — code layout and runtime flow.
3. `TASK_AUTHORING.md` — how to implement tasks correctly.
4. `PROMPT_SYSTEM.md` — prompt bundles, variants, and metadata.
5. `SHARED_UTILITIES.md` — helper placement and reuse rules.
6. `BUILD_VALIDATION.md` + `VALIDATION_ERROR_CODES.md` — pre-finalize checks and error taxonomy.
7. `CODE_DOCUMENTATION.md` + `CODE_REVIEW_GUIDELINES.md` + `LESSONS_LEARNED.md` — quality/process guidance.
8. `STATUS.md` + `TODO.md` — current snapshot and backlog.
