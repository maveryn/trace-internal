# TRACE Docs

This folder is the source of truth for contracts, architecture, and task authoring.

## Suggested read order
1. `BLUEPRINT.md` — normative ABI/contracts.
2. `SYSTEM_ARCHITECTURE.md` — code layout and runtime flow.
3. `TASK_AUTHORING.md` — consolidated task authoring + quickstart checklist.
4. `TASK_FAMILY_VARIANTS.md` — family/variant taxonomy and planned task variants.
5. `TILE_TASK_SETUP.md` — concrete v1 setup for single-board coordinate-grounded tile tasks.
6. `PROMPT_SYSTEM.md` — prompt bundles, variants, and metadata.
7. `SHARED_UTILITIES.md` — helper placement and reuse rules.
8. `BUILD_VALIDATION.md` + `VALIDATION_ERROR_CODES.md` — pre-finalize checks and error taxonomy.
9. `CODE_DOCUMENTATION.md` + `CODE_REVIEW_GUIDELINES.md` — quality/process guidance.
10. `STATUS.md` + `TODO.md` — current snapshot and backlog.
11. `../task-reviews/README.md` — task-by-task review workflow and artifacts.
