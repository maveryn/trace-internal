# Three-D CountQA Object References

This manifest records the online visual references used to extend the TRACE
`three_d` CountQA-style renderer. No external images, meshes, or CAD files are
copied into the repo; these links were used only to check silhouettes and
common visual features for native synthetic glyphs.

## Implementation Notes

- Loose objects are added to `OBJECT_CLUSTER_EXTRA_SHAPE_TYPES` and rendered by
  native projected glyphs in the shared object-scene renderer.
- Tiles, holes, slots, compartments, vents, windows, doors, and drawer pulls are not
  added to the loose-object pool. They are represented by `surface_fixture`
  because they are repeated elements of a surface, not standalone tabletop
  objects.
- Distractor filtering groups visually related families: writing tools,
  flat papers/soft flat objects, hardware, containers, plant forms, miniature
  furniture, and decorative/game pieces.
