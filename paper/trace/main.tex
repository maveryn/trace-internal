\begin{abstract}
\sloppy
Reinforcement learning with verifiable rewards has advanced language
reasoning, but multimodal training still lacks visual data that combine broad
coverage with exact, reproducible supervision. We present \trace, a
taxonomy-guided environment for multidomain visual reasoning. \trace separates
visible scene grammars from executable reasoning tasks, allowing visual form,
program structure, and bounded query variation to be controlled independently.
Each instance is generated from latent semantic state and yields a rendered
image, prompt, typed answer, verifier state, and replayable execution trace.
The environment contains 1,000 tasks across 277 scenes and 11 visual domains,
with controlled variation in semantic content, layout, palette, typography,
context, and rendering. Answer-only RLVR on 64,000 generated instances improves
the macro-average over 24 external benchmarks by 3.51 percentage points for
Qwen2.5-VL-3B and 4.06 points for Qwen2.5-VL-7B; the 7B model improves every
benchmark in the suite. \trace therefore provides both a controlled task
environment and evidence that procedural breadth can transfer beyond its
synthetic imagery.
\end{abstract}
