\section{Experimental Setup}
\label{sec:experiments}

We evaluate whether answer-based RLVR on the broad procedural task distribution
in \trace improves visual reasoning beyond the base model. The primary
comparison holds the model family, task split, generated instances, training
budget, and benchmark protocol fixed, and compares the unmodified base model
with a model trained using typed answer rewards from \trace.

Evaluation reports in-domain validation separately from transfer to external
benchmarks. Per-benchmark scores accompany macro-averages so that gains in one
task family do not conceal regressions in another.
