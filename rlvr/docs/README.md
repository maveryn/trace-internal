# RLVR Docs

This folder is the source of truth for RLVR-specific training, export, validation, and implementation notes.

## Core RLVR workflows
- `RLVR_EXPORT.md` — building TRACE training parquet files for the local RLVR stack.
- `EXTERNAL_RLVR_VALIDATION.md` — fixed external validation-pack layout and RLVR validation usage.

## RLVR implementation notes
- `VERL_CHANGELOG.md` — local RLVR fork changes relevant to TRACE.
- `RLVR_STATUS.md` — current RLVR integration status.
- `TODO.md` — RLVR-side backlog and implementation notes.
- `CELLWISE_GRPO.md` — cellwise reward / advantage notes.
- `GRPO_TESSERAE_DETAILS.tex` — detailed GRPO/Tesserae notes.

TRACE repo-wide docs stay under `docs/`. That tree should only link to RLVR docs, not duplicate them.
